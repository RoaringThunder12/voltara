# Heresy outbreak system - Component 3: Historical heresy outbreak #
####################################################################
# Christianity-only. Each named heresy has a 50-year cooldown (timed global
# variable) between successive outbreaks. The first outbreak of a named heresy
# uses its historical founder; subsequent outbreaks ("resurgences") use a
# secondary historical figure if available, otherwise a generic anonymous
# preacher. Paulician / Iconoclast / Adoptionist / Messalian have no anchor
# founder and are always anonymous repeating outbreaks.
#
# Resurgence weight is 30% of a first-fire weight, so historical outbreaks are
# strictly more likely than their resurgences.
#
# Pre-declaration vs already-declared: the heresy faith may be in either state
# at the time of any outbreak (first or resurgence). The pre-declaration setup
# spawns a rite of the parent faith; the already-declared setup converts the
# epicenter directly to the heresy faith.
